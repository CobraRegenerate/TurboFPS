## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please follow the process below:

### How to Report

**Preferred method:** [Private Security Advisory](https://github.com/CobraRegenerate/TurboFPS/security/advisories/new)

**Alternative:** Email вЂ” security@turbofps.dev

### What to Include

- Step-by-step reproduction
- Affected version
- Severity assessment (Low / Medium / High / Critical)
- Proof-of-concept (if applicable)
- Suggested fix (optional)

### Response Timeline

- **Initial response:** 48 hours
- **Triage result:** 5 business days
- **Patch release:** 30 days (Critical: 72 hours)

### Safe Harbor

We pledge not to pursue legal action against security researchers who:
- Act in good faith
- Avoid privacy violations or data destruction
- Use only reporting channels described above
- Give us reasonable time before public disclosure

## Security Best Practices for Users

- Always download from **official channels** (GitHub Releases or links in this repository)
- Verify the SHA-256 checksum before running
- Never share your system credentials
- Report suspicious behavior immediately
