## Highlights
- Batch optimization mode
- Automatic game detection
- AMD FidelityFX Super Resolution support
- 15 new game profiles (total: 45)

## Changelog

### Added
- Batch optimization mode — optimize multiple games in one pass
- Automatic game detection via process scan
- AMD FidelityFX Super Resolution support in GPU Optimization
- 15 new game profiles (CS:GO legacy, Destiny 2, GTA V, Rainbow Six Siege, and more)

### Changed
- New interface with dark theme
- Optimization engine rewritten — lower CPU usage while active
- Package size reduced from 6.1 MB to 4.2 MB

### Deprecated
- Legacy `.tbp` profile format — JSON profiles are the standard from now on
