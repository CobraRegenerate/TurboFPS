## Changelog

### Added
- Support for Windows 11 24H2 (build 26100)
- Game profiles: Marvel Rivals, Delta Force, Frag Punk
- Quick Boost global hotkey: `Ctrl+Shift+F1`
- Dark theme UI refresh
- GPU clock overlay (off by default)

### Changed
- Memory cleaner algorithm — standby list flush is 20% faster
- Settings panel reorganized into tabs
- Updated download mirror to GitHub Releases

### Fixed
- Crash on Windows 10 1803 when opening Settings
- Incorrect FPS counter on multi-monitor setups
- Memory leak in Process Killer after 50+ kills

## Upgrade notes
Extract over the previous version. Your custom profiles in
`%APPDATA%\TurboFPS\profiles\` are preserved. The legacy `.tbp` profile
format (deprecated in 1.1.0) is no longer read — convert via
Profiles → Import legacy.
